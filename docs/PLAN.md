# TraceAI: Build Plan (iOS 17+, Swift 6, SwiftUI)

## Context
New app in an empty folder (`C:\Users\razee\OneDrive\Documents\3DApp`) on a **Windows** PC. The PC reaches your brother's **Mac over Tailscale** (SSH + macOS Screen Sharing/VNC).
- **Compile checks** run on GitHub Actions (macOS runner) or over SSH on that Mac.
- **Device builds** are made on that Mac and reach your iPhone through TestFlight. The camera and Vision features cannot be tested in the Simulator.

The work is split into small phases. Each phase runs in a fresh session, reads only **Contracts** and its own phase, and writes 1–2 files of no more than ~200 lines each.

## Decisions (locked)
- SwiftUI, iOS 17.0, Swift 6 language mode, iPhone only, portrait only. No third-party dependencies until Phase 7.
- Xcode project generated by **XcodeGen** (`project.yml`). We never hand-write a `.pbxproj`.
- **Free:** photo import, 3 samples, full line-art stencil, all camera tools, Auto-Snap Paper, Hand Mask. **Pro:** the 4-step layer breakdown.
- The 3 samples are drawn in code (UIBezierPath). No binary assets.
- No Photos permission (`PhotosPicker` runs outside the app's process). The camera is the only permission.
- All camera frames are processed on-device and never stored.
- **One coordinate space:** the video-data connection is rotated to upright portrait. The paper quad, the hand mask and the warped stencil all live in that frame space, and each is drawn `scaledToFill` exactly like the `resizeAspectFill` preview, so the layers line up.

## Contracts (fixed; every phase codes against these)
```swift
// StencilProcessor.swift
struct StencilSet: Sendable {
    let full: UIImage        // free stencil: black lines on transparent
    let layers: [UIImage]    // exactly 4, cumulative: 1 Shapes, 2 Outlines, 3 Details, 4 Shading
}
enum StencilError: Error { case invalidImage, processingFailed }
enum StencilProcessor {
    static func makeStencil(from image: UIImage) async throws -> StencilSet
}

// SampleSketches.swift
enum SampleSketch: String, CaseIterable, Identifiable, Sendable {
    case cat, flower, house
    var id: String { rawValue }
    var title: String { get }
    func makeStencilSet(size: CGSize = CGSize(width: 1024, height: 1024)) -> StencilSet
}

// PaywallManager.swift
enum PaywallPlacement { static let unlockLayers = "unlock_4_step_breakdown" }
@MainActor @Observable final class PaywallManager {
    static let shared = PaywallManager()
    private(set) var isPro: Bool
    func triggerPaywall(placement: String)
    func restorePurchases() async
    func refreshEntitlements() async
}

// VisionTracker.swift
struct PaperQuad: Sendable, Equatable {        // normalized 0–1, origin top-left,
    var topLeft: CGPoint, topRight: CGPoint    // in the upright portrait camera frame
    var bottomLeft: CGPoint, bottomRight: CGPoint
}
struct TrackerOutput: @unchecked Sendable {
    let quad: PaperQuad?
    let handMask: CGImage?                     // hand pixels on transparent; nil if none
    let frameSize: CGSize                      // upright frame size in pixels
}
final class VisionTracker: @unchecked Sendable {
    func process(_ buffer: CVPixelBuffer, trackPaper: Bool, maskHands: Bool) -> TrackerOutput // video queue only
    func reset()                                                                             // clears EMA state
    static func warpStencil(_ stencil: UIImage, to quad: PaperQuad, canvasSize: CGSize) -> UIImage?
}

// CameraController.swift
@MainActor @Observable final class CameraController {
    enum Status { case idle, unauthorized, unavailable, running }
    private(set) var status: Status
    private(set) var isTorchOn: Bool
    private(set) var isLocked: Bool
    var isPaperTrackEnabled: Bool              // didSet → engine
    var isHandOcclusionEnabled: Bool           // didSet → engine
    private(set) var trackedPaperQuad: PaperQuad?   // frozen while isLocked
    private(set) var handMaskImage: CGImage?
    private(set) var frameSize: CGSize              // canvasSize for warpStencil
    func attachPreview(_ layer: AVCaptureVideoPreviewLayer)
    func start() async                         // asks permission, configures, starts
    func stop()
    func setTorch(_ on: Bool)
    func setFocusExposureLocked(_ locked: Bool)
}
struct CameraPreview: UIViewRepresentable { let controller: CameraController }

// TraceAIApp.swift
struct TraceSession: Identifiable { let id = UUID(); let stencil: StencilSet }

// TracingView.swift
struct TracingView: View { let stencil: StencilSet }
```
Swift 6 rules:
- `AVCaptureSession`, `AVCaptureDevice` and the video delegate live in a private `final class CaptureEngine: @unchecked Sendable` that has its own serial queues. Its flags are guarded by an `OSAllocatedUnfairLock`.
- `CameraController` (on MainActor) only calls the engine and publishes the state.
- Shared `CIContext`s are `nonisolated(unsafe) static let` if the compiler complains.

## Phase 2: SampleSketches.swift (~180 lines)
- `UIGraphicsImageRenderer`, transparent background, black round-cap strokes.
- Each sample has 4 stroke groups (construction shapes → outline → details → hatching). These become the cumulative `layers`; `full` = layers 1–3.
- Samples: cat face, flower, house. Simple original drawings.

## Phase 3: StencilProcessor.swift (~180 lines, hardest so far; strongest model)
Run everything in `Task.detached(priority: .userInitiated)` with one shared `CIContext`.
1. **Normalize:**
   - `CIImage(image: uiImage, options: [.applyOrientationProperty: true])`.
   - If a portrait photo still comes out rotated on a device, add `.oriented(CGImagePropertyOrientation(uiImage.imageOrientation))`.
   - Downscale so the long side is at most 1600 px (`CILanczosScaleTransform`).
2. **Remove background:**
   - Run `VNGenerateForegroundInstanceMaskRequest`. If a subject is found, build a mask with `generateScaledMaskForImage(forInstances: allInstances, from:)` and place the subject on white with `CIBlendWithMask`.
   - If nothing is found or the request throws, keep the original image. Never fail here.
3. **Gray:** `CIColorControls` (saturation 0, contrast about 1.1).
4. **Line helper** `lines(blur:threshold:)`:
   - `.clampedToExtent()` → `CIGaussianBlur` → `CILineOverlay` → `.cropped(to: source.extent)`.
   - Pass all 5 `CILineOverlay` parameters explicitly: `inputNRNoiseLevel 0.02`, `inputNRSharpness 0.71`, `inputEdgeIntensity 1.0`, `inputThreshold threshold`, `inputContrast 50.0`.
   - The layers:
     - **L1 Shapes:** blur 10, threshold 0.3, plus the silhouette outline: `CIMorphologyGradient` on the mask → `CIMaskToAlpha` → **black-ink matrix**.
     - **L2 Outlines:** blur 4, threshold 0.15.
     - **L3 Details:** blur 0, threshold 0.1.
     - **L4 Shading:** `CIColorPosterize` (4 levels) → `CIColorInvert` → `CIMaskToAlpha` → black-ink matrix with `aVector (0,0,0,0.35)`.
   - **Black-ink matrix:** `CIColorMatrix` with the r, g and b vectors all `(0,0,0,0)`. `CIMaskToAlpha` outputs white, and this turns it into black on transparent.
5. **Assemble:** `layers[n]` = L1…L(n+1) stacked with source-over. `full` = `layers[2]`. Render RGBA8 sRGB → `UIImage`.

## Phase 4: CameraController.swift (~200 lines)
- **CaptureEngine:**
  - `sessionQueue` + `videoQueue`; back `.builtInWideAngleCamera`; preset `.high`.
  - `AVCaptureVideoDataOutput`: `kCVPixelFormatType_32BGRA`, `alwaysDiscardsLateVideoFrames = true`, delegate on `videoQueue`.
  - Data-output connection `videoRotationAngle = 90` (upright portrait buffers). Check `isVideoRotationAngleSupported` before setting it.
- **Frame gate** in `captureOutput`. Return immediately when:
  - both flags are off,
  - less than 1/15 s has passed since the last processed frame,
  - the previous frame is still processing.

  When `ProcessInfo.thermalState >= .serious`, drop to 10 fps.
- **Per frame:** `tracker.process(buffer, trackPaper: paperOn && !locked, maskHands: handOn)`, then hop to MainActor and set:
  - `trackedPaperQuad`: only while unlocked, so **Lock freezes the last anchor** even if an arm covers a corner.
  - `handMaskImage` and `frameSize`.
  - Turning a toggle off clears its value. Turning paper tracking on calls `tracker.reset()`.
- **`attachPreview(layer)`:** `layer.session = engine.session`, `.resizeAspectFill`, and the preview connection rotated to 90.
- **`start()`:**
  - Ask camera permission. Denied → `.unauthorized`; no device → `.unavailable`.
  - Otherwise configure, `startRunning` on `sessionQueue`, and set `.running`.
- **`setTorch`:** check `hasTorch`, then `lockForConfiguration` and set `torchMode`.
- **`setFocusExposureLocked(true)`:**
  - `focusMode = .locked` and `exposureMode = .locked`, each guarded by `is…ModeSupported`.
  - White balance only when `!device.isAdjustingWhiteBalance && device.isWhiteBalanceModeSupported(.locked)`. This avoids an `NSInvalidArgumentException` on real devices.
  - Unlocking returns all three to `.continuousAuto…`.
- **`stop()`:** torch off, `stopRunning`, clear the quad and the mask.
- **`CameraPreview`:** a UIView whose `layerClass` is `AVCaptureVideoPreviewLayer`. `makeUIView` calls `controller.attachPreview(view.previewLayer)`.

## Phase 4B: VisionTracker.swift (~190 lines, strongest model)
Create the request objects and one `CIContext` once, and reuse them every frame. Run requests through `VNImageRequestHandler(cvPixelBuffer:orientation: .up)`; the buffer is already upright.
1. **Paper Corner Auto-Tracking:** `VNDetectDocumentSegmentationRequest`.
   - Take the first `VNRectangleObservation` with confidence ≥ 0.6. Flip Vision's bottom-left origin to top-left (`y = 1 − y`).
   - Smooth each corner with an EMA: `s += 0.25 × (new − s)`.
   - If detection is lost, keep the last quad for 10 frames, then return nil.
   - `warpStencil(_:to:canvasSize:)`:
     - Fit the stencil's aspect inside the paper so it doesn't stretch: compute an inset rect in the unit square and map its 4 corners into the quad bilinearly.
     - Convert to pixels in `canvasSize` with CI's bottom-left origin (`y = (1 − y) × h`).
     - `CIFilter.perspectiveTransform()` → composite over a clear canvas → crop to the canvas rect → render to `UIImage`.
2. **Hand Occlusion:** `VNGeneratePersonInstanceMaskRequest`.
   - `generateScaledMaskForImage(forInstances: allInstances, from:)` gives the mask.
   - Downscale the frame to at most 960 px on the long side, then `CIBlendWithMask(input: frame, background: clear, mask)` → a `CGImage` of the hand pixels only. No person → nil.
   - If it runs under 15 fps or misses a bare hand on the device, swap in `VNGeneratePersonSegmentationRequest` (`.balanced`). The output stays the same.
3. **`reset()`** clears the EMA and lost-frame counters.

## Phase 6: TracingView.swift + TracingDock.swift (each ≤200 lines)
- **Layer stack, bottom to top:**
  1. `CameraPreview`
  2. Stencil
  3. Hand mask: `Image(decorative:)`, `.resizable().scaledToFill()`, same full-screen frame as the preview, `.allowsHitTesting(false)`, so the lines sit *under* your fingers and pencil
  4. Top bar
  5. Dock
- **Stencil, snapped:** when Auto-Snap is on and a quad exists:
  - Show `VisionTracker.warpStencil(current, to: quad, canvasSize: camera.frameSize)` full-screen with `.scaledToFill()`.
  - Compute it in `.task(id: quad)` off the main thread, never inside `body`.
  - Manual gestures are off while snapped.
  - If this stutters on the device, switch to `.projectionEffect` with a homography, which needs no re-render.
- **Stencil, manual:**
  - Modifiers in strict order: `.scaleEffect` → `.rotationEffect` → `.offset`.
  - `MagnifyGesture` ⊕ `RotateGesture` ⊕ `DragGesture(minimumDistance: 10)`, applied at the same time. Commit the values when the gesture ends.
  - When locked: `.gesture(…, including: .none)` and `.allowsHitTesting(false)`.
- **Current image:** for Pro, `layers[step-1]` (default step 3). Otherwise `full`.
- **Fallback screens:** `.unauthorized` shows an explanation and an "Open Settings" button. `.unavailable` shows a message.
- **Top bar:** close button, plus reset-alignment (hidden while locked).
- **TracingDock** (`.ultraThinMaterial`):
  - Opacity `Slider(0.1...1.0)`.
  - Segmented picker 1–4 with the stage name under it. Not Pro: the picker is disabled and covered by the "Unlock 4-Step AI Breakdown" button.
  - Two compact pills, **Auto-Snap Paper** and **Hand Mask**, bound to the camera flags.
  - Flashlight toggle.
  - A prominent **Lock Canvas & Focus** button with haptic feedback.
- **Lifecycle:** on appear, `isIdleTimerDisabled = true` and `camera.start()`. On disappear, undo both. Use `scenePhase` to stop and resume the camera.

## App Store Review checklist
- **2.1 Completeness:** no placeholder paywall, URLs or "coming soon" in the submitted build. Superwall and products must be live. Review notes explain tracing, Auto-Snap, Hand Mask and how to reach the paywall.
- **2.3 Accurate metadata:** real screenshots. The "AI" claims are backed by on-device Vision ML. The 4 steps look clearly different.
- **4.3 Spam:** tracing apps are a crowded category. Lead with on-device stencil generation, paper auto-snap, hand occlusion and the step breakdown. Check "TraceAI" is free in App Store Connect.
- **3.1.1 / 3.1.2 Purchases:** in-app purchase through StoreKit/Superwall, with Restore in the app. The paywall shows price, period and renewal terms, with Privacy and Terms (EULA) links, which also go in App Store Connect.
- **5.1.1 Privacy:**
  - Ask for the camera only when the tracing screen opens, with a specific purpose string that mentions paper and hand detection.
  - The app stays usable if access is denied. No Photos permission.
  - Provide a privacy policy URL and the privacy manifest. Frames are never stored or uploaded.
- **5.1.2:** disclose Superwall analytics in the App Privacy labels. Not the Kids category.
- **4.0 Design:** test every iPhone size, and iPad compatibility mode.
- **2.5.1:** public APIs only.

## Token-saving workflow
- **One phase per fresh session** (new chat or `/clear`). Prompt: *"Implement Phase N from docs/PLAN.md. Read only the Contracts and Phase N sections; don't open other Swift files unless a compile error points there."*
